at commit `9166c6a918cda73fe4c05912ed9b06446bb95e60`, retaining its LICENSE.

## Installer, Host And Build Toolchain

Ubuntu installer media and host packages, Linux, GNU utilities, BusyBox, Ansible
and `community.general` retain their respective GPL and other package licenses.
Redistributing a USB image/appliance includes those binaries and may require
corresponding-source provision. Preserve Ubuntu package copyright records and
obtain exact package/source inventories for each generated installer image.
The BSL grant applies only to Magic Stick's automation, not to Ubuntu or kernels.

K3s, Kubernetes, containerd, Flux, Envoy, Keycloak and many operators have
Apache-2.0 project licenses, but their images/Helm packages contain additional
dependencies. Chart templates, controller binaries, GPU drivers, CUDA, ROCm,
Intel runtimes and firmware each require independent review. CUDA/driver
redistribution terms must not be inferred from an Apache-licensed operator.

Dashboard build dependencies include MPL-2.0 `lightningcss`/native bindings,
BlueOak-1.0.0 `lru-cache`, CC0-1.0 `mdn-data`, and MIT/BSD/ISC/Apache tooling.
Their status as build tools is recorded in the inventory. If a tool or its code
enters a shipped artifact, apply that license's distribution/source obligations.
