Noch eine Frage?

Ist MagicStick ein Hardwareprodukt? +

MagicStick ist Software für deine vorhandene Infrastruktur. Du kannst einen physischen Server, eine virtuelle Maschine, ein dediziertes Ubuntu-System oder ein vorhandenes Kubernetes-Cluster nutzen. Die Abbildung oben ist eine Illustration der Plattform.

Brauche ich eine GPU? +

Nein. Lokale Inferenz ist auch auf CPU möglich; externe Anbieter benötigen keine lokale GPU. vLLM unterstützt die katalogisierten CPU-, NVIDIA-, AMD- und Intel-Ziele, Ollama CPU, NVIDIA und AMD. Das Dashboard bietet nur erkannte, verfügbare Kombinationen an. Die konkrete Modell- und Hardwarekompatibilität bleibt entscheidend.

Bleiben meine Daten bei mir? +

Lokale Modellinferenz läuft auf deiner Infrastruktur. Ob Anwendungen weitere Daten übertragen, hängt von ihren Integrationen und deiner Konfiguration ab. Wenn du externe Modelle einbindest, werden die entsprechenden Anfragen an deren Anbieter gesendet. Für Installation und Modell-Downloads werden externe Quellen verwendet.

Kann ich meine eigenen Modelle und Tools verwenden? +

Du kannst kompatible Modelle über Hugging Face, die Ollama Library oder direkte Referenzen wählen und externe Provider ergänzen. Eigene Anwendungen greifen über die OpenAI-kompatible Schnittstelle zu. Kataloge, Kubernetes-APIs und Overlays ermöglichen weitere Integrationen.

Wo finde ich technische Details? +

Im Dokumentationsindex findest du Installation, Architektur, Modelle, Authentifizierung und Betrieb. Der Quellcode und die Konfigurationsbeispiele liegen im selben öffentlichen Repository.
