BEFORE YOU START

A few good questions.

Is MagicStick a hardware device?+

No. It is software you install on your own server, VM or Kubernetes cluster. The USB stick is an installation medium, not a special AI accelerator.

Do my data and models stay local?+

Local inference runs on your infrastructure. External providers receive the requests you send to them, and applications may have their own integrations. Installation and downloads use external sources. Self-hosting is not an automatic offline guarantee.

Will every model work on every GPU?+

No. Engine, device, drivers, model and memory must match. The dashboard checks capabilities and availability, but a memory estimate is not proof that a workload will fit. Read the compatibility reference first.

What about realtime voice models?+

There is a separate experimental vLLM-Omni path with specific profiles. OpenAI-compatible chat does not imply audio or Realtime support. See the Realtime guide.

Where can I get help?+

Start with the troubleshooting guides and support policy. Project support is best-effort, without a guaranteed response time. Keep credentials and private deployment information out of public issues.
