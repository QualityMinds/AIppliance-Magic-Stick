# Get started

Magic Stick turns a dedicated computer into a managed AI appliance. You use a
browser to run models, provision applications and control who can use them.

1. Read [features and limits](features.md).
2. Check [hardware and network requirements](requirements.md).
3. [Choose your installation path](../installation/README.md): USB, a new VM,
   an existing Ubuntu host, or an existing Kubernetes cluster.
4. [Create your first administrator](../installation/first-run-setup.md).
5. [Get your first model response](first-model.md).

Already installed? Go directly to the [dashboard overview](../user-guide/dashboard.md).
