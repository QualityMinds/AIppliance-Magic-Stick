# Integration reports

Dated report bodies are deliberately excluded from the handbook's full-text
search. Use this index to find historical evidence; use current guides to operate
the appliance.

These are dated evidence snapshots, not current user instructions or blanket
hardware certifications. Each report records its version and distinguishes local
checks from physical-appliance acceptance.
